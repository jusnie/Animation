# Animation — MIKAY

Short-form 2D动画 about a girl stick figure surviving the first days of an outbreak.
Everything in this repo is generated: the plates are illustrated, the sound effects and
the film-look VFX are synthesised, and the films are assembled by scripts.

## Films

| Film | Length | File | Notes |
| --- | --- | --- | --- |
| **EP 0 — THE DAY BEFORE** | 35 s | `render/mikay-ep0.mp4` | **animated**: the end of an ordinary day |
| THE DAY BEFORE (v1) | 39 s | `render/mikay-day0.mp4` | still plates, superseded |
| DAY 1: THEY'RE OUTSIDE | 43 s | `render/mikay-day1.mp4` | still plates |

All are 1920×1080, 24 fps, with narration, burned-in subtitles, a running timecode
(top right), and a real 35 mm film emulation. **No background music** — narration and diegetic
sound only.

### EP 0 is animated

There is a real 2-D rig behind the character (`tools/mikay_rig.py`): a skeleton of hips,
knees, ankles, shoulders, elbows and hands, driven by pose functions — `pose_walk(phase)`,
`pose_stretch(t)`, `pose_brush(t)`, `pose_sit()`, `pose_lie(t)` — plus per-frame breathing,
blinks, mouth flaps and ponytail swing. `tools/animate.py` turns each narration line into a
shot: it picks a 16:9 crop out of a background plate and draws the rig into it frame by
frame. There are **no camera moves** and **no dissolves**; the motion is the character.

## Layout

```
art/pre/          day-0 plates      art/frames/   day-1 plates
art/               character sheet + thumbnail
audio/             narration mp3s (source of truth for the subtitles)
audio/sfx/         synthesised effects (regenerated by tools/make_sfx.py)
assets/fonts/      Poppins 700/800/900
docs/              VFX provenance, sound design, packaging rules
references/        the three thumbnails the style was learned from + style notes
story/             beat sheets, character bible, locked narration scripts
tools/             script data, SFX generator, mixer, video builder, VFX port
render/            output
```

## Render

```bash
./render.sh ep0          # effects -> mix -> animated picture (default)
./render.sh ep0 video    # picture only
./render.sh day0         # the older still-plate film
```

## Guarantees the pipeline enforces

- **Subtitles cannot drift.** The spoken string and the burned-in caption are the same
  value in `tools/script_data.py`; `build_video.py` asserts the SRT and the on-screen
  text reproduce it word for word.
- **Subtitles are on the word.** Ep 0's narration is *one audio file per sentence*, and a
  caption is nothing but `[segment start, segment start + measured speech length]` — no
  proportional guessing, no title-card offset. `build_audio.py` also trims each clip's
  encoder lead-in silence, so the first syllable and the caption land together
  (measured drift ≤ 1 frame).
- **No camera moves.** Fixed crops, hard cuts; motion comes from the rig and the film look.
- **The voice always wins.** Effects are ducked 6 dB under every spoken line.
- **VFX is not generated.** `tools/vfx.py` is a port of an MIT-licensed GitHub project,
  credited in `docs/VFX.md`.
