# MIKAY — DAY 1 — sound design & packaging

Everything audible in the film is generated by the repo's own scripts — no samples, no
stock audio, nothing to license. Two generators feed one mixer:

```
tools/make_sfx.py    ->  audio/sfx/*.wav      22 effects, synthesised
tools/make_music.py  ->  audio/music/*.wav    7 score cues, synthesised
tools/build_audio.py ->  render/mikay_day1_mix.wav   narration + SFX + ducked score
tools/build_video.py ->  render/mikay-day1.mp4       picture + burned-in captions
```

`render.sh` runs all four in order.

## Mix levels

The narration is the reference; everything else is placed under it.

| Element | Level | Note |
| --- | --- | --- |
| Narration | −21 dB RMS | uncompressed, always on top |
| Score (beds normalised) | −46 … −29 dB RMS | each cue normalised to −20 dBFS RMS first, then set 10 dB down |
| Score while she speaks | −38 … −33 dB RMS | side-chain ducked another 6 dB, 280 ms release |
| Effects | peaking −12 … −2 dBFS | transient-forward, so they cut without volume |

Measured headroom between the voice and the score is **≈ 12–17 dB under every line**, so
the narrator is never fighting the music. Master peak is −1 dBFS with no clipped samples.

| 0:35 | She opens the door | latch + hinge + air, wind through the doorway, low boom as the horde steps aside, quiet horde |
| 0:40 | End card | low bloom, then silence |

## Score map

| Cue | Plays | Palette |
| --- | --- | --- |
| `tension` | 0:00 – 0:10 | D minor drone, 50 BPM heartbeat pulse, high shimmer |
| `cozy` | 0:10 – 0:19 | C major 6/9 pad, lazy out-of-time plucks |
| `mistake` | 0:19 – 0:21 | warmth drains: C minor cluster over a low pedal |
| `dread` | 0:21 – 0:27 | D minor + E♭ cluster, no rhythm, 44 BPM pulse |
| `turn` | 0:27 – 0:35 | ostinato pedal, filter opening 320 Hz → 2.6 kHz |
| `resolve` | 0:35 – 0:40 | open fifth, hollow and bright, highs shimmer |
| `end` | 0:40 – 0:43 | one low bloom, fades to silence |

## Timecode on screen

- Burned into the **upper right**, opposite the MIKAY badge in the upper left.
- Format `MM:SS`, ticking once a second from `00:00`, in a dark pill with a red
  recording dot, so it reads as a camcorder stamp and not as part of the title.
- Fixed-advance digit spacing — the pill never changes width as the numbers roll.
- Not shown on the end card.
- To switch to a story-specific stamp (`DAY 1 · 06:12`) edit `timecode_layer()` in
  `tools/build_video.py`.

## Publishing rule

Every deliverable is uploaded to Google Drive **with public link sharing on**
(`anyone` / `reader`, no sign-in required) right after the render — the user should
never have to ask for it. Link-discovery stays off, so the file is reachable by link
but does not appear in search results.
